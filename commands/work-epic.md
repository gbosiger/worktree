Use the work-prepare skill to create one backlog epic from: $ARGUMENTS

Inspect relevant project context and existing tickets to avoid duplicates.
Write outcome/value, scope/exclusions, observable criteria, dependencies, and
open questions. Use a group parent only if supplied or already agreed; otherwise
create a standalone epic. Respect stated roles; ask only for missing essentials.
Do not start implementation or create a branch. Validate the board and report
the new ID and path. With no description, ask for the intended feature first.
