description: Create a behavioral story inside an epic
---

Use the work-prepare skill to create one backlog story from: $ARGUMENTS

Resolve the parent epic from the request or unambiguous agreed context; ask if
missing or ambiguous. Read it and check existing children for overlap. Describe
the user’s situation, one useful change, and examples of success and a meaningful exception.
Respect stated roles. Do not implement or start the ticket. Validate the board
and report the new ID and path. With no description, ask what behavior is needed.
