# Worktree Tickets convention

Minimal repository-local work tracking: editable Markdown, stable IDs, explicit
human–agent handoffs, and no mandatory external service. Python 3.10+ runs the
optional CLI; ordinary editors and Git remain sufficient for manual work.

This is a reference index. Read only what the current operation needs:

- [Format](docs/FORMAT.md): hierarchy, status folders, IDs, and metadata.
- [Authoring](docs/AUTHORING.md): useful epics, bounded stories, and acceptance criteria.
- [Lifecycle](docs/LIFECYCLE.md): transitions, dependencies, review, and acceptance.
- [Git](docs/GIT.md): branches, commit messages, and branch-local limitations.
- [Installation](docs/INSTALLATION.md): command setup and adoption in other projects.

Historical material is separate: [migrations](docs/MIGRATIONS.md) and
[changelog](CHANGELOG.md). Skills should not load these during ordinary work.
